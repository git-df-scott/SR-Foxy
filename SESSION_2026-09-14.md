## Read this first if you read nothing else

`research/19` section 8 contains a **retraction**. I published a claim that
both of research/17's surviving first bands on J25533 fail a necessary
condition, so that the survivors were dead. It was wrong. The cause was my own
screen calling `Link.simplify('global')` before building the link exterior.

**`Link.simplify('global')` deletes split unknot components.** A trefoil with a
split unknot has Alexander-module order 0 and two components; after
`simplify('global')` it is the bare trefoil, order `a^2 - a + 1`, one component.
Any test whose intended pass is "split knot plus unknot" is inverted by this.
Check every existing script that simplifies before measuring a link invariant.

The corrected numbers on 25533: 29 of 61 first-stage links have positive rank,
the known-good control passes, and both research/17 survivors pass. No target is
eliminated. The retraction is recorded in full rather than edited away.

## Astra's lemma

Audited in `research/19`. The geometry is correct; genus zero is redundant given
connectedness; one configuration (complementary annulus joining the two
components of L, disk bounding K') must be excluded by hand and is excluded only
by connectedness of the concordance, not by the Euler count.

The open item is unchanged: **"generic Alexander rank is a link-concordance
invariant" is asserted, not cited.** It is not multivariable Fox-Milnor. Until a
primary source is in the ledger, every rank-based exclusion is conditional.

Astra's rank-zero result on the 1,092 normalized matches reproduces
independently, by link-exterior Alexander order rather than triangulation
groups: 1,092 examined, 0 positive rank, 0 errors, both before and after the
simplify fix (those links are certified nonsplit, so they carry no unknot
component to delete).

Terminology: `snappy`'s `Manifold.alexander_polynomial()` on a link exterior is
the **order of the Alexander module**, not the classical multivariable `Δ_L`.
On the Whitehead link it returns `a^2 b^3 - a b^2 - a b + 1`, whose `b = 1`
specialisation is `(a-1)^2`, so it does not obey the Torres condition. Vanishing
still means positive module rank, which is the condition wanted.
